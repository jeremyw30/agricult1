# Messages templates pour la collaboration Agri-Cult

## 📧 Invitation de collaborateur

### Email/Message d'invitation initial

```
Objet : Collaboration Agri-Cult - Invitation développement

Salut [Prénom],

Merci beaucoup pour ta proposition — ça me ferait super plaisir de t'avoir sur Agri-Cult ! 

Voici le plan rapide :
• Je t'ajoute sur le dépôt privé GitHub
• On fera un petit onboarding (30–45 min) pour te présenter l'architecture et les tâches prioritaires
• Avant d'accéder au code sensible, je te demanderai de signer un petit accord de confidentialité/contribution (rien de lourd)

L'objectif est de créer une application de gestion agricole moderne avec Symfony, et ton expertise sera vraiment précieuse !

Dis-moi tes dispo cette semaine pour qu'on se cale la réunion d'onboarding.

À bientôt !
— Jérémy

PS : Tu peux déjà jeter un œil à la doc du projet : [LIEN VERS README]
```

## 🎯 Agenda réunion d'onboarding

### Réunion initiale (30-60 min)

```
AGENDA ONBOARDING - AGRI-CULT
Durée : 45 minutes

1. Présentation du projet (10 min)
   • Objectifs et vision
   • Fonctionnalités actuelles
   • Roadmap prévue

2. Architecture technique (15 min)
   • Stack : Symfony 7.2, PHP 8.2+, MySQL
   • Structure du code (entités, contrôleurs, etc.)
   • Workflow Git et PR

3. Environnement de développement (10 min)
   • Installation locale
   • Outils recommandés
   • Scripts de setup

4. Première mission (5 min)
   • Tâche d'onboarding assignée
   • Critères de validation
   • Timeline

5. Questions & Next steps (5 min)
   • Réponses aux questions
   • Planning prochaine session si besoin
   • Contacts et communication

Actions :
☐ Accès GitHub confirmé
☐ Environnement local installé
☐ Première tâche assignée
☐ Prochaine réunion planifiée (si nécessaire)
```
